## 漢字語源・意味フラッシュカード

JLPTレベル別60字の漢字を語源・読み・例文付きフラッシュカードで学習できる間隔反復対応の日本語漢字学習ツール。

### 機能
- 60字の漢字データ内蔵（N5-N4: 20字、N3-N2: 20字、N1: 20字）
- CSS 3D flipアニメーション（transform: rotateY）によるカードめくり
- カード裏に音読み・訓読み・意味・語源・例文2文を表示
- 自己評価（知ってた/曖昧/要復習）による間隔反復出題調整
- JLPTレベルフィルター・ランダムシャッフルモード
- デッキ完走後に「要復習のみ再挑戦」オプション
- localStorage による学習進捗保存

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- CSS 3D transform: rotateY によるカードフリップアニメーション
- localStorage 永続化
